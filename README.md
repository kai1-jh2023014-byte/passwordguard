# ローカルパスワード管理

ブラウザ内（`localStorage`）にだけ保存する、シンプルなパスワード管理 Web アプリです。金庫全体をマスターパスワードで AES-GCM 暗号化します。サーバーへの送信は行いません。

## 機能

- マスターパスワードで金庫の作成・ロック解除
- ログイン情報の追加・編集・削除
- 検索、パスワード表示/非表示、クリップボードコピー
- ランダムパスワード生成

## 必要環境

- Node.js 20 以降

## 使い方

```bash
npm install
npm run dev
```

ブラウザで [http://127.0.0.1:3847](http://127.0.0.1:3847) を開きます。

## 注意

- マスターパスワードを忘れるとデータは復元できません。
- ブラウザのデータを消すと金庫も消えます。重要な情報は別途バックアップしてください。
- 本番利用向けの監査済み製品ではありません。個人のローカル利用を想定しています。

## 技術スタック

- Next.js (App Router) + TypeScript + Tailwind CSS
- Web Crypto API（PBKDF2 + AES-GCM）
- shadcn/ui
